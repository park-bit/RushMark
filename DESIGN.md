# Rushmark

Rushmark helps creators find a short, shareable moment in a long recording. The public page demonstrates the output with playable clips. The studio starts with the source video and keeps the controls for making clips together.

## Identity

Use the Rushmark wordmark on light backgrounds and its white version on the dark studio frame. Use the square mark for the favicon and collapsed sidebar. The orange comes from the existing clip palette.

| Role | Colour | Use |
| --- | --- | --- |
| Primary action | `#FF8B33` | Make clips and the active navigation icon |
| Ink | `#251A15` | Public headings and text on orange buttons |
| Frame | `#202524` | Studio sidebar, with a related dark green on the public stage |
| Quiet surface | `#F4F5F1` | Workflow section and grouping related controls |
| Dark orange | `#A9480A` | Public headline emphasis and visible keyboard focus |

## Public page

Pair the source-link field with a playable vertical sample in the first section. Keep playback under the visitor’s control. Label each caption style and expose its selection to assistive technology. On narrow screens, place the form before the preview and allow the submit button its own row.

Use a large sans-serif headline with Georgia italic for the second line. Reserve that type pairing for the public page. Use thin borders and colour changes for separation and interaction.

## Studio

Group Overview, Video library and Settings above the creator list. Highlight the current view with a subdued warm fill and apricot icon. Keep the orange animated strip behind the composer and use its static colours for reduced motion. Use Geist with system sans-serif fallbacks. Keep the composer, upload button, options and primary action together. Show setup actions before activity on a new workspace. Offer the tour from Home and the account menu. Keep errors close to the action they affect and let the user read them at their own pace.
